# JARVIS（音声だけで話せるAI秘書）

画面を開いておくと常に聞き取りを続け、呼びかけると反応して、声で返事をします。チャット欄はありません。

## 画面の見かた
- 待機中：ほぼ静かな細い一本線
- あなたが話している間：横線があなたの声に合わせて動く
- 考えている間：色の混ざったもやもやがゆらゆら動く
- 話している間：横線が波打つ
- 右上の「PANELS」で、マイク音量・応答時間・会話ログなどのパネルを表示/非表示

## 使い方
- 最初に画面をタップして起動（マイクの許可が必要です）
- 「ジャービス」または「秘書」と呼びかけて、そのまま用件を話す
- 呼びかけだけでも反応します（ピッという音のあとに、続けて話す）
- 返事のあと約8秒は、呼びかけなしで続けて話せます
- 画面をタップしても、呼びかけの代わりになります
- 呼び名は、`index.html` の先頭にある `WAKE_WORDS` で変えられます

## 仕組み
- ブラウザの音声認識が常時聞き取り → 呼びかけを検出 → テキストを `/api/voice`（Vercel）へ送信
- 普通の会話は、Groqが返答を作る（速い）
- 「天気」「ニュース」「今日の」など最新の情報が必要そうな質問は、GeminiがGoogle検索して答える（`GEMINI_API_KEY` が必要。失敗したときは、Groqが「今は調べられない」と答える）
- 返答は、ブラウザが日本語で読み上げ
- 常時聞き取りが使えない端末では、画面タップで録音 → Groq Whisperで文字起こし、に自動で切り替わります

## ファイル
- `index.html` … 画面、常時聞き取り、読み上げ
- `api/voice.js` … 返答生成（サーバー側。キーはここだけで使う）
- `manifest.json` … ホーム画面に追加するための設定
- `vercel.json` … 検索に時間がかかっても途切れないための設定
- `README.md` … このファイル

## 公開手順（スマホだけでOK）
1. GitHubで新しいリポジトリを作り、`Add file > Upload files` で、`index.html`、`manifest.json`、`vercel.json`、`api`フォルダごとアップロード
2. Vercelで `Add New > Project` から、そのリポジトリをImport（設定はそのままでDeploy）
3. Vercelの `Settings > Environment Variables` に追加して、Redeploy
   - `GROQ_API_KEY` … GroqのAPIキー（必須）
   - `APP_PASSCODE` … 自分だけが使うための合言葉（おすすめ）
   - `GEMINI_API_KEY` … Google AI Studioで作るキー（天気・ニュースなど最新情報の検索用。なくても会話は動きます）
4. 発行されたURLをスマホのブラウザで開く

更新するときは、GitHubで同じ名前のファイルを上書きアップロードすれば、Vercelが自動で反映します。

## 注意（常時聞き取りの限界）
- ブラウザの仕組み上、画面を点けてこのページを開いている間だけ聞き取ります（画面ロック・別アプリ表示中は止まります）
- Androidの Chrome が一番安定します。iPhoneのSafariは、常時聞き取りが途切れやすく、タップ操作が必要になることがあります
- 電源につないで、画面を点けたままにするのがおすすめです
- 使うモデルを変えたいときだけ、環境変数 `GROQ_CHAT_MODEL` / `GROQ_STT_MODEL` / `GEMINI_MODEL` で上書きできます（普通は入れなくてOK）
- 天気は、通信回線から推定した場所を使います。違う場所のときは「東京の天気は？」のように場所を言ってください
- APIキーは、チャットやGitHubには貼らず、Vercelの環境変数にだけ入れてください
